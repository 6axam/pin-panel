[micropad_guide.md](https://github.com/user-attachments/files/28115590/micropad_guide.md)# MicroPad — Инструкция по сборке, прошивке и настройке

Проект карманного макропада на 16 кнопок на базе контроллера **ESP32-C3 SuperMini**. 
Устройство работает как беспроводная Bluetooth-клавиатура (BLE). Настройка клавиш выполняется через обычный браузер по шнуру (Web Serial API) без использования сторонних серверов или софта.

---

## 1. Схема и распиновка (Железо)

Кнопки подключены по матричной схеме $4 \times 4$, что позволяет опрашивать 16 кнопок, используя всего 8 пинов контроллера. За питание отвечает модуль зарядки **BQ25606**.

### Питание и делитель напряжения
* **Питание:** Выходы `U+` и `U-` контроллера зарядки BQ25606 заводятся на пины `5V` и `GND` платы ESP32-C3 через механический выключатель `S1`.
* **Контроль батареи:** Плюс аккумулятора (`bat+`) подключен к пину **GPIO1** (`bat_pin`) через делитель напряжения на двух резисторах по `10 кОм` (R1 и R2). Это понижает напряжение батареи в два раза, чтобы измерительный аналоговый пин контроллера не сгорел и мог корректно определять процент заряда.

## 2. Прошивка контроллера

### Настройка Arduino IDE
1. Установи в менеджере плат пакет **esp32** от *Espressif*.
2. Выбери плату: **ESP32C3 Dev Module**.
3. В менеджере библиотек найди и поставь библиотеку:
   * **BleKeyboard** (автор *T-vK*) — для эмуляции клавиатуры.

### Заливка кода
1. Открой скетч `pin_panel_copy.ino`.
2. Подключи плату к компьютеру по USB-шнуру.
3. В параметрах платы выбери частоту процессора **80 MHz** (в коде жестко прописано `setCpuFrequencyMhz(80)` для сильного снижения энергопотребления и экономии заряда батареи).
4. Выбери активный COM-порт и нажми **Загрузить**.

## 3. Работа с веб-конфигуратором

Для изменения раскладки используется файл `сетка.html`. Достаточно открыть его локально на компьютере в любом браузере с поддержкой Web Serial (Chrome, Edge, Opera).

### Настройка кнопок шаг за шагом:
1. **Подключение:** Нажми кнопку **«Подключить устройство»** на странице конфигуратора и выбери COM-порт твоей платы. При успешном соединении статус сменится на зеленый, а плата передаст в браузер все текущие сохраненные бинды.
2. **Профили:** Устройство поддерживает 3 независимых пресета (раскладки). Переключение между ними происходит кнопками «Пресет 1», «Пресет 2» и «Пресет 3». Номер активного профиля пишется в память платы и сохраняется при перезагрузке.
3. **Режим привязки:**
   * **Вариант А:** Кликни мышкой по нужной ячейке (от `B1` до `B16`) в окне браузера.
   * **Вариант Б:** Включи тумблер *«Режим привязки»*. Теперь при нажатии физической кнопки на самом макропаде на экране автоматически всплывет окно настроек именно для этой кнопки.
4. **Запись клавиши:** В окне настройки кликни по серой зоне *«Кликни сюда и нажми клавишу»*. Появится оранжевый статус ожидания. Нажми на клавиатуре компьютера нужную комбинацию (например, `Ctrl + Shift + C`). Веб-интерфейс перехватит кнопки и покажет их коды.
5. **Сохранение:** Нажми кнопку **«Сохранить бинд»**. Конфигурация отправится по Serial в контроллер и запишется в энергонезависимую память (библиотека `Preferences`).

## 4. Как этим пользоваться

1. Включи тумблер питания `S1` на корпусе MicroPad.
2. Включи Bluetooth на ПК, ноутбуке или телефоне, запусти поиск устройств.
3. Найди устройство с именем **StreamPad Combo** (имя прописано в коде инициализации BLE) и выполни сопряжение.
4. Макропад готов к работе. При нажатии физических кнопок срабатывает быстрый матричный опрос с программным антидребезгом в 50 мс, и плата мгновенно эмулирует нажатие стандартных клавиш.
5. Раз в 10 секунд плата замеряет вольтаж на `bat_pin`, пересчитывает его в проценты и отправляет статус заряда по BLE. Текущий уровень батареи макропада будет отображаться прямо в системном трее Windows или настройках Bluetooth телефона.
