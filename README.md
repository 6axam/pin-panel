# Pin Panel: Беспроводной Макропад (BLE Combo Device)

Компактный беспроводной конфигуратор макрокоманд на базе **ESP32** с веб-интерфейсом управления через **Web Serial API**. Устройство определяется компьютером как комбинированная BLE клавиатура/мышь и позволяет на лету переназначать функции клавиш без перепрошивки контроллера.

---

## 🛠 Поддерживаемое железо

Прошивка написана и оптимизирована под платформу **ESP32** (с поддержкой Classic Bluetooth / BLE).

* **Микроконтроллер:** ESP32, ESP32-S3 (отлично подходят платы с объемом памяти N16R8 или аналогичные).
* **Матрица кнопок:** 16 тактовых кнопок, собранных в классическую сетку матричного типа 4х4.
* **Пины подключения матрицы (по умолчанию в коде):**
    * Строки (`rowPins[4]`): `GPIO 2, 3, 10, 0`
    * Столбцы (`colPins[4]`): `GPIO 4, 5, 6, 7`
* **Контроль батареи:** `GPIO 1` (аналоговый пин для подключения к плюсовому контакту аккумулятора).
* **Питание:** Li-Ion/Li-Po аккумулятор (3.7V) с модулем заряда (TP4056).

## 📂 Структура файлов проекта

1. **`pin_panel_copy.ino` (Прошивка C++)**
    * Отвечает за инициализацию BLE-стека (эмуляция клавиатуры и мыши через библиотеку `BleCombo`).
    * В реальном времени сканирует матричную клавиатуру 4х4.
    * Хранит бинды во внутренней энергонезависимой памяти контроллера (NVS через библиотеку `Preferences`) — настройки клавиш не сбрасываются при отключении питания устройства.
    * Поддерживает до **3 независимых профилей** раскладки, переключаемых «на лету».
    * Организует двусторонний текстовый протокол обмена данными с ПК через аппаратный Serial-порт.

2. **`сетка.html` (Веб-интерфейс / Конфигуратор)**
    * Полностью автономная графическая панель управления в темных тонах (Cyberpunk style).
    * Использует современный **Web Serial API** для прямого подключения к COM-порту ESP32 прямо из браузера (требуются Google Chrome, Microsoft Edge или Opera). *Никаких сторонних драйверов или серверов устанавливать не нужно.*
    * Позволяет визуально выбирать ячейки, назначать на них клавиши клавиатуры (с модификаторами Ctrl, Shift, Alt, Win), кнопки мыши, а также переключать рабочие профили.
    * Обладает системой автоматического поиска и переподключения к ранее использовавшемуся порту.

## 🚀 Инструкция по запуску и использованию
<img width="721" height="504" alt="image" src="https://github.com/user-attachments/assets/c809e446-5ae0-450c-8dcd-053ec17f0b4e" />

### Шаг 1. Сборка устройства (Железо)
1. **Подключение матрицы кнопок:** Спаяйте тактовые кнопки в матричную сетку 4х4. Подключите выводы строк к пинам `GPIO 2, 3, 10, 0`, а выводы столбцов — к пинам `GPIO 4, 5, 6, 7` платы ESP32.
2. **Система питания:** Подключите аккумулятор к контактам `BAT+` и `BAT-` модуля зарядки типа TP4056(у меня BQ25606). 
3. **Разводка питания и выключатель:** Проведите линию от плюса аккумулятора через выключатель и защитный диод напрямую к пину `3V3` платы ESP32. Пин `GND` платы соедините с минусом аккумулятора.
4. **Контроль батареи:** Подключите аналоговый пин `GPIO 1` напрямую к плюсовому контакту аккумулятора для замера уровня заряда.

### Шаг 2. Прошивка контроллера
1. Установите в Arduino IDE актуальный пакет плат ESP32.
2. Установите библиотеку **`BleKeyboard`**.
3. Откройте файл `pin_panel_copy.ino`, при необходимости скорректируйте пины в массивах `rowPins` и `colPins` под вашу реальную схему распайки.
4. Выберите вашу плату в меню *Инструменты -> Плата* и загрузите код в ESP32.

### Шаг 3. Первое сопряжение с ПК
1. Включите Bluetooth на вашем компьютере/ноутбуке.
2. Подайте питание на прошитую ESP32 через тумблер. В списке доступных для сопряжения Bluetooth-устройств появится **"Pin Panel"**.
3. Выполните сопряжение. Теперь ОС распознает устройство как родную клавиатуру и мышь.

### Шаг 4. Настройка горячих клавиш (Конфигурация)
1. Подключите макропад к компьютеру с помощью USB-кабеля.
2. Откройте файл `сетка.html` в браузере Chrome или Edge.
3. Нажмите кнопку **«Подключить Pin Panel»** в верхнем углу интерфейса и выберите соответствующий COM-порт вашей платы.
4. После успешного коннекта веб-интерфейс автоматически считает текущую информацию о сохраненных биндах из памяти ESP32.
5. **Процесс привязки:**
    * Кликните на любую из 16 ячеек виртуальной сетки.
    * Выберите тип действия: *Клавиатура* или *Мышь*.
    * Для клавиатуры: кликните по полю ввода и зажмите нужную комбинацию на вашей физической клавиатуре (например, `Ctrl + Shift + Alt + F12`), скрипт автоматически перехватит коды клавиш.
    * Нажмите **«Сохранить»**. Настройки мгновенно отправятся в ESP32 и запишутся в память. Кабель можно отключать — макропад готов к беспроводной работе!

## 🛰 Протокол обмена данными (Serial API)

Устройства общаются по текстовому протоколу (скорость порта `115200 baud`, символ окончания строки `\n`):
* `GET_BINDS` — запрос от ПК на чтение всех биндов.
* `SET_B=слот,type,modifier,key` — команда записи бинда в выбранный слот (0-15).
* `DEL_B=слот` — удаление макроса из памяти устройства.
* `SET_PROFILE=ID` — быстрая смена активного профиля (0, 1 или 2).
